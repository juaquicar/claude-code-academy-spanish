# 01 — ¿Qué es Claude Code?

*10 minutos* · [Vídeo](https://www.youtube.com/embed/fl1DSmwQKKY)

**Al terminar sabrás:** qué es Claude Code y en qué se diferencia de Claude.ai · qué es un agente de IA · qué puede hacer Claude Code en la práctica · los tres conceptos que hay que tener en la cabeza para usarlo bien.

---

## La definición

**Claude Code es una herramienta de codificación agéntica** que entiende tu base de código, edita tus ficheros, ejecuta comandos y se integra con tus herramientas de desarrollo para que termines antes.

Está disponible en:

- el **terminal**
- **Visual Studio Code**
- la app de escritorio **Claude Desktop**
- la **web**
- los IDE de **JetBrains**

## Qué lo separa de Claude

Si ya has usado Claude.ai, la diferencia es esta: **Claude Code tiene acceso directo a tus ficheros, a tu terminal y a toda tu base de código.** En vez de copiar y pegar código de un lado a otro, entra y hace el trabajo él mismo.

> **El diferenciador clave es que Claude Code funciona como un AI Agent.**

## Qué es un agente

**Un agente de IA es software que puede interactuar con su entorno y ejecutar acciones para completar un objetivo definido.**

En el fondo esto funciona teniendo **un modelo de lenguaje operando en un bucle en tiempo real**. Los agentes pueden tener acceso a herramientas, a servicios externos o incluso a otros agentes de IA para alcanzar sus objetivos.

> **Trampa de examen.** Un agente **no** es «un chatbot que responde preguntas en tiempo real», ni un editor con autocompletado, ni un servicio en la nube que aloja proyectos. Es **IA que ejecuta acciones para completar objetivos**. Esa distinción es literalmente la pregunta 1 del quiz oficial.

## Qué puede hacer en la práctica

| Capacidad | Ejemplo |
|---|---|
| **Leer y entender tu base de código** | Pedirle que explique una funcionalidad o que rastree un bug por todo el código |
| **Editar ficheros de todo el proyecto** | Refactorizar una función y actualizar todos los ficheros que la referencian |
| **Ejecutar comandos de terminal** | Lanzar tu script de build, pasar los tests, instalar paquetes — y usar la salida para decidir qué hace después |
| **Buscar en la web** | Consultar documentación o referencias de API actualizadas |

## Los tres conceptos que hay que tener presentes

**La ventana de contexto.** Piénsala como la memoria de trabajo de Claude. Cabe mucho, pero no todo a la vez. Aquí es donde entra lo «agéntico»: Claude busca formas estratégicas de encontrar respuestas dentro de tu código **sin cargarlo entero en contexto**.

**Pide permiso.** Por defecto, Claude Code te pregunta antes de ejecutar comandos o hacer cambios. Tú mandas siempre, tanto si prefieres un enfoque de intervención constante como uno de dejar hacer.

**Puede equivocarse.** Como cualquier herramienta, Claude Code no es perfecto. Puede malinterpretar tu intención, introducir un bug o sobre-diseñar una solución. **Estar en el bucle es lo que te permite pillarlo pronto.**

## Conclusiones

Claude Code es una herramienta de codificación agéntica. Lee tu base de código, edita tus ficheros, ejecuta comandos y se conecta a herramientas externas para que entregues antes. Puedes usarlo hoy mismo en el terminal, VS Code, JetBrains y la app de escritorio de Claude.
